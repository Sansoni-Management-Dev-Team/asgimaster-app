# Native member app references

The native app's required behaviour is canonical in the [feature specifications](features/README.md). [HLDD 04](hldd/04-member-app.md) explains its API and device boundaries. The approved visual direction is in [visual/accessibility requirements](phase-2-visual-alignment.md).

The [mobile implementation](../apps/mobile/) is authoritative for component structure, storage compatibility, dependencies and native configuration. Migration sequencing, prototype snapshots and verification evidence belong in PRs and thread artifacts outside `docs/`.
