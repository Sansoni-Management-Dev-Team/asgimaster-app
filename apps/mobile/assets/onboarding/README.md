# Concept 2 media

These are the existing local Concept 2 assets, bundled for native/offline use:

- `customer-stories-loop.mp4`: 720×960, 16.8-second H.264, silent monochrome customer montage. Copied unchanged from the workspace `app/assets/concepts/`.
- `customer-stories-poster.webp`: the original matching first-frame fallback.
- `caveat-medium.ttf`: the existing Caveat Medium handwriting font used by the letter. Its SIL Open Font License is included in `OFL.txt`.

The source montage was assembled for the web concept from the customer excerpts documented in `app/concepts/README.md` (Wistia IDs `3r2omnn2nz`, `fg07k2ud13`, `q50bg5s92t`, `uwyywfjcbo`). This migration makes no new media selection and publishes nothing externally.
