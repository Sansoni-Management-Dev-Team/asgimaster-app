# mlai-sansoni

Native iOS and Android member app. Expo + React Native + TypeScript.

## Requirements

- Node 22 or newer (Node 26 in use)
- Xcode for iOS, Android Studio or a JDK for Android
- Watchman is recommended on macOS: `brew install watchman`

## Getting started

```sh
npm install
npm start        # dev server, then press i (iOS) or a (Android)
npm run ios      # or run straight onto a simulator
npm run android
```

The `ios/` and `android/` folders are generated by `expo prebuild` and are not committed. Run `npx expo prebuild` when you need the native projects locally.

## Scripts

- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript, no emit
- `npm test` — Jest
- `npm run format` — Prettier

## Stack

Expo SDK 57, React Native 0.86, React 19.2, Expo Router, NativeWind 4, TanStack Query, Zustand, Jest with React Native Testing Library, EAS Build and Update.

See `AGENTS.md` for conventions and `docs/` for product context.

## Web design prototype

The independently runnable member-experience prototype lives in
[`prototypes/member-web/`](prototypes/member-web/README.md). It is a design and
behavior reference, not a replacement for the Expo app in `src/`.

```sh
npm run prototype:web       # http://127.0.0.1:4173/app/#onboarding
npm run prototype:web:test  # standalone Node regression suite
```

These commands need no additional dependencies. The existing native commands,
routes and dependency lockfile are unchanged; the prototype is excluded from
native Jest/ESLint and root formatting discovery.
